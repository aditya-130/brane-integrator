What happens
  1. Creates ~/brane/data/{name}/dataset.csv from your uploaded file
  2. Writes a data.yml manifest pointing to that file
  3. Runs brane data build data.yml to register the dataset in Brane's local index

After this, BraneScript can reference the dataset with new Data { name := "..." } and Brane will resolve it to the file on disk.
